# Version 1.17.0 (2026-11-26) - 1.17.1 (2026-11-27)

## Editor

C# 15.

New output tag `<mark>` - mark text for `print.scrollTo` or `print.replace`.

Improved:
- Auto-sized intellisense popup windows.

Fixed bugs:
- Sometimes crashes after closing a file.
- Output tag `<image>` may not work.
- (1.17.1) Bug in 1.17.0: sometimes exception when showing an intellisense window.

## Library

New classes:
- `Path2`. Replaces `pathname`.
- `PathFilter`. Path glob matching etc.

New members:
- `filesystem.list`. Replaces the `enumX` methods. Glob patterns, faster.
- `filesystem.copy` supports glob patterns.
- `string` extension operator `/` joins paths.
- `print.scrollTo`, `print.replace`. Used with the new output tag `<mark>`.

New parameters:
- `EnumUI` callback function for filtering and setting text/tooltip.

Improved:
- Can use `using` with `wpfBuilder` panels: `using (b.R.StartGrid()) { /*auto-indented code*/ } //don't need b.End()`.
- Autotext triggers: if the trigger string starts with a non-word character, the trigger also works when the typed trigger text is preceded by a word character.
