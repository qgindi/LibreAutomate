# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io/), certificate by [SignPath Foundation](https://signpath.org/).

## What will be signed
LibreAutomate releases starting with v1.17.0.

#### Signed files

The installer (`LibreAutomate.msi`) and `exe`/`dll` files built from this repository. Files built from forks are not signed. Files originating from NuGet packages are unchanged.
