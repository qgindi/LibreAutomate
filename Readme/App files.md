## Run-time files and folders
When you build the solution (platforms `Any CPU`, `ARM64` and `x86`), you get all files and folders used by LibreAutomate at run time. They are in folder `_`. Here is the list.

- Folders `32`, `64` and `64\ARM` contain program files for CPU architectures.
  - `apphost.exe`  
	.NET app host template. Used when compiling a script to `exe`.  
	Taken from .NET SDK: `C:\Program Files\dotnet\packs`

  - `AuCpp.dll`  
	The unmanaged part of the automation library.  
	Generated by project `Cpp` (C++).

  - `Au.DllHost.exe`  
	Loads `AuCpp.dll` of this CPU architecture.  
	Generated by project `Au.DllHost`.

  - `Scintilla.dll`  
	Code editor control.  
	Generated by project `Scintilla` (modified copy of [Scintilla](https://www.scintilla.org) sources).

  - `7za.exe`  
	Compress/extract 7z files.  
	Taken from 7-Zip Extra: https://www.7-zip.org/download.html

- Folder `Debugger`  
	.NET debugger.  
	Files generated by solution `netcoredbg` in external repo https://github.com/qgindi/netcoredbg.

- Folders `Default`, `Templates`  
	Content files copied from various source folders.

- Folder `Roslyn`  
	C# code compiler/analyzer and intellisense features.  
	Files generated by solution `Roslyn` in external repo https://github.com/qgindi/roslyn.

- Folder `runtimes`  
	Some files of used NuGet packages.

- `Au.Editor.exe`, `Au.Editor.dll`, `Au.Editor.*.json`, `Au.Editor.xml`  
	The C# script editor/manager app.  
	Generated by project `Au.Editor`. Resources added by project `BuildEvents`.

- `Au.Editor-arm.exe`  
	Arm64 version of `Au.Editor.exe`.  
	Generated by project `BuildEvents`.

- `Au.Task.exe`, `Au.Task-arm.exe`  
	Apphost for managed dlls of script processes.  
	Generated by project `BuildEvents`.

- `Au.dll`, `Au.xml`  
	The automation library.  
	Generated by project `Au`.

- `Au.Controls.dll`, `Au.Controls.xml`  
	WPF controls.  
	Generated by project `Au.Controls`.

- `AxMSTSCLib.dll`, `MSTSCLib.dll`  
	.NET interop library for the system library `mstscax.dll`. Used for the Picture-in-Picture feature.  
	Generated in Visual Studio: `aximp.exe c:\windows\system32\mstscax.dll`

- `Microsoft.Web.WebView2.*.dll`  
	WebView2 control. Used to display documentation.  
	NuGet package `Microsoft.Web.WebView2`, referenced in project `Au.Editor`.

- `NuGet.*.dll`  
	Some NuGet features.  
	NuGet packages, referenced in project `Au.Editor`.

- `doc.db`, `ref.db`  
	.NET documentation (for intellisense) and reference assemblies.  
	Created by project `DatabasesEtc`.  
	Data taken from .NET SDK: `C:\Program Files\dotnet\packs`

- `icons.db`  
	XAML icons.  
	Created by project `DatabasesEtc`.  
	Data taken from: https://github.com/MahApps/MahApps.Metro.IconPacks

- `winapi.db`  
	Windows API declarations for C#.  
	Created by script `WinAPI converter.cs`.  
	Data taken from: https://github.com/microsoft/win32metadata

- `doc-ai.db`, `toc-ai.yml`  
	LibreAutomate documentation optimized for AI.  
	Created by script `LA docs doc-ai.db.cs`.

- `doc-html.db`  
	LibreAutomate documentation for displaying in LA.  
	Created by script `LA docs doc-html.db.cs`.

- `xrefmap.yml`  
	LibreAutomate documentation article ids for links.  
	Generated by DocFX, which is executed by script `Au docs.cs`.

- `toc.json`  
	Table of contents of LibreAutomation documentation. Used in the Help panel.  
	Generated by script `LA docs toc.json.cs`.

- `default.exe.manifest`  
	Default manifest for apps created by LibreAutomate.

### Files generated by scripts or external projects

Some of the above files are automatically downloaded from https://github.com/qgindi/LA-downloads/releases/tag/v1.0.0 when building the solution. They cannot be easily generated by everyone. They were generated by C# scripts (in the `Scripts` folder) or projects in other GitHub repositories ([roslyn](https://github.com/qgindi/roslyn), [netcoredbg](https://github.com/qgindi/netcoredbg)). When building the solution, a build event script (project `BuildEvents`) downloads and extracts file `git-clone-LA-binary.7z` if need. These files are compatible with all GitHub commits that use the same .NET x.x version as the last commit.

## Installer files

- `LibreAutomate.msi`  
	Installs LibreAutomate. Contains the above listed files.  
	Created by script `LaInstaller.cs` and [Master Packager Dev](https://www.masterpackager.com/).

- `MsiCA.dll`  
	MSI custom actions. Embedded in `LibreAutomate.msi`.  
	Generated by project `MsiCA`.
